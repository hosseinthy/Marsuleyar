مرسوله‌یار — پروژهٔ آزمایشی اندروید

این پروژه نسخهٔ اولیه است، نه نسخهٔ نهایی برای استفادهٔ واقعی.
پیاده‌سازی‌شده: فرم ثبت دستی، ذخیره محلی SQLite، جلوگیری از بارکد تکراری، وضعیت تحویل، جست‌وجو.
هنوز پیاده‌سازی نشده: اسکن دوربین بارکد، OCR فارسی/انگلیسی، عکس برچسب، پشتیبان‌گیری/بازیابی، رمزگذاری و آزمایش کامل.

ساخت APK با GitHub:
1) همه فایل‌های ZIP را در مخزن GitHub بارگذاری کنید؛ مسیر .github/workflows/build-apk.yml نیز باید حفظ شود.
2) به تب Actions بروید و workflow با نام Build Morsulehyar APK را اجرا کنید.
3) پس از پایان موفق، وارد اجرای workflow شوید و Artifact به نام Morsulehyar-debug-apk را دانلود کنید.
4) ZIP دانلودشده را باز کنید؛ فایل app-debug.apk داخل آن است.

برای اطلاعات واقعی گیرندگان از این نسخه استفاده نکنید تا قابلیت‌های ناقص تکمیل و آزمایش شوند.
